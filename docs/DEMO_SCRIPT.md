## Evidence-change demonstration

Keep the real checked-in arXiv snapshot. Show baseline versus active weighting for multiple roles; some rounded scores may stay unchanged. To demonstrate a source refresh, run `npm run refresh:research`, inspect the timestamp/hash/records, run tests and rebuild before the session. A fresh request may return identical papers. Do not alter a title to manufacture a visible live-data change. The automated test uses a clearly labelled synthetic fixture to verify sensitivity; that fixture is not published as factual evidence.

## Six-slide outline

1. **Who needs this?** A Malaysian graduate or career switcher choosing a credible next learning step. Show the problem and intended output.
2. **One connected journey.** Profile → evidence → roles → learning → SDGs → uncertain futures. Explain the visual encoding briefly.
3. **Working proof.** Live evidence-to-score comparison, contribution table and learning export. Show real sources and dates.
4. **Local context with boundaries.** DOSM geography, state granularity and no demographic/location scoring. Explain why US O*NET references need local validation.
5. **Human agency and uncertainty.** Two hypothetical scenarios, editable assumptions, free-first resources, 17 goal pathways and text alternatives.
6. **What is built and what is next.** Test/build evidence, limitations, evaluation plan, actual team contributions and tool declaration.

No slide count or duration in this outline is represented as an organiser requirement.

## Questions to rehearse

**What makes it AI-powered?** Classical TF-IDF retrieval and transparent rule-based topic/matching methods. No runtime LLM. Be precise about this modest MVP; do not promise predictive accuracy.

**Why not predict job losses?** Task exposure, adoption, labour demand and individual outcomes are different quantities. The available snapshot does not justify a Malaysian loss forecast.

**How do you update?** Official-source scripts validate and version dated snapshots; review and rebuild publish them. Research weights are opt-in; curated factual summaries require review.

**Why 3D?** It gives the six modules a connected spatial interface. Heights/order encode disclosed quantities where appropriate. Equivalent text panels preserve access and make the claims inspectable.

**Is it fair?** Names and location do not affect skill coverage, which tests confirm. This is not a full fairness evaluation; self-assessment, resource access and taxonomy coverage can still bias usefulness.

**What did the team build?** Answer with actual participant contributions after reviewing and adapting this AI-assisted handoff. Do not imply that generated work was independently authored by participants.
