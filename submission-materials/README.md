# SHIFTATLAS 3D - SELADEVS UTHM

[Live application](https://sdc-2026-seladevsuthm.replit.app/) · [Source repository](https://github.com/hzqfarhan/SDC2026-SELADEVSUTHM)

We built a connected 3D career atlas for Malaysian learners: reviewed profiles, explainable role coverage, affordable learning, source-linked Malaysian labour context, SDG pathways and uncertain AI-adoption scenarios. Atlas Quest adds a playable route through the concepts.

Career Council assigns one generative model four roles: profile reviewer, career explorer, learning planner and critic. Later stages build on earlier suggestions, and the critic challenges their reasoning to support comparison. E5 separately supplies semantic retrieval.

Our 14-slide pitch uses editable Segoe UI text, low-poly visuals, the official SELADEVS team mark and original UN SDG artwork. The PDF matches the PowerPoint. The companion video includes the pitch, actual prototype views and our recorded E5 CUDA execution evidence. It runs approximately 6 minutes 51 seconds and includes captions.

We recorded direct CUDA execution for E5 retrieval and the Qwen profile-review stage using fictional text. The six-role application gateway and complete four-pass Council have separate acceptance checks; the technical declaration records the scope of each completed check. Our prototype uses authored rubrics and hypothetical scenarios, with no claim of measured employment outcomes.

The video uses Windows synthetic narration and edited actual prototype captures. Our coding tools include OpenAI Codex, GPT-5.1 Sol, Qoder and Cortex Code (CoCo). Codex also substantially assisted research and materials; OpenAI image generation produced the app icon and low-poly concept artwork. Model, data and third-party asset terms remain separate from the original project's Apache 2.0 licence. Official signed forms and private contact details are kept outside this public folder.
